EduCloud – Secure Trainer-Student File Portal

Project Overview

EduCloud is a secure file-sharing and assignment management system
designed for trainers and students.

The project combines Linux system administration and AWS cloud
services to provide centralized file storage, controlled access,
backup, monitoring, and high availability.

Objectives

- Provide secure sharing of study materials.
- Allow students to submit assignments.
- Manage user permissions using Linux groups and ACLs.
- Automate backup and archival operations.
- Store files securely using Amazon S3.
- Improve application availability using AWS services.

- User and Group Management
- Access Control Lists (ACL)
- NFS

AWS

- Amazon EC2

- Application Load Balancer
- Auto Scaling Group
- Amazon S3
- Amazon RDS MySQL
- AWS Lambda
- Amazon SNS
- Amazon API Gateway
- Amazon CloudFront
- AWS IAM
- Amazon CloudWatch

Project Features

1. Trainer and student user management.
2. Role-based file access.
3. Centralized materials and assignment directories.
4. Automated backup using shell scripts.
5. S3 storage and archival.
6. Database storage using RDS MySQL.
7. Email notifications using SNS.
8. High availability using ALB and Auto Scaling.
